Simple neural network — scaled worked example

The same network and data as the original worked example, with exam scores, grades and biases divided by 100

Why scale? In the original example, exam scores near 100 make the gradients run into the thousands, so even a learning rate of 0.0001 moves the weights by 0.3 to 0.5 in the first step. That switches P₁ off for good (see section 11 of the original). Dividing the exam scores and grades by 100 puts every number near 1. Dividing the biases by 100 too keeps the network exactly the same: every z, P and prediction below is the original divided by 100, and every loss is divided by 10,000. With every number near 1, a learning rate of 0.1 trains the network in a few thousand epochs, where the original needs over a million.

All values on this page are copied from the original worked example, including any changes you made there. To change them, edit them on the original page.

3. Forward pass equations (symbolic)

Hidden layer — pre-activation

z₁ = w₁₁·e₁ + w₂₁·e₂ + w₃₁·e₃ + b₁
z₂ = w₁₂·e₁ + w₂₂·e₂ + w₃₂·e₃ + b₂

Hidden layer — post-activation (ReLU)

ReLU(z) = max(0, z)

P₁ = max(0, z₁)
P₂ = max(0, z₂)

Output layer — linear (no activation)

pred = w₄·P₁ + w₅·P₂

7. Backpropagation equations (symbolic)

Loss function (MSE)

y = true label, pred = network output

L = ½(y − pred)²

Output layer gradient

∂L/∂pred = −(y − pred)

Gradients for output weights

∂L/∂w₄ = ∂L/∂pred · P₁ = −(y − pred) · P₁
∂L/∂w₅ = ∂L/∂pred · P₂ = −(y − pred) · P₂

Gradients flowing back to hidden neurons

∂L/∂P₁ = ∂L/∂pred · w₄ = −(y − pred) · w₄
∂L/∂P₂ = ∂L/∂pred · w₅ = −(y − pred) · w₅

Through ReLU activation

ReLU'(z) = 1 if z > 0, else 0

∂L/∂z₁ = ∂L/∂P₁ · ReLU'(z₁)
∂L/∂z₂ = ∂L/∂P₂ · ReLU'(z₂)

Gradients for hidden layer weights (into P₁)

∂L/∂w₁₁ = ∂L/∂z₁ · e₁
∂L/∂w₂₁ = ∂L/∂z₁ · e₂
∂L/∂w₃₁ = ∂L/∂z₁ · e₃
∂L/∂b₁ = ∂L/∂z₁

Gradients for hidden layer weights (into P₂)

∂L/∂w₁₂ = ∂L/∂z₂ · e₁
∂L/∂w₂₂ = ∂L/∂z₂ · e₂
∂L/∂w₃₂ = ∂L/∂z₂ · e₃
∂L/∂b₂ = ∂L/∂z₂

Weight update rule

η = learning rate

w ← w − η · ∂L/∂w b ← b − η · ∂L/∂b
